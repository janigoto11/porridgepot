## backend-lists-api

Toteuta backendiin ostoslistojen hallinta: lisää DynamoDB-pohjaiseen tallennuskerrokseen (olemassa olevaa USERS_TABLE-taulua hyödyntäen, esim. LIST#-etuliitteellä) ja handler.mjs-reitityksiin päätepisteet ostoslistojen hakemiseen, luomiseen, nimen muokkaamiseen, poistamiseen sekä listan tuotteiden lisäämiseen ja poistamiseen. Reitit vaativat voimassa olevan kirjautuneen käyttäjän session-evästeen samaan tapaan kuin /api/me. Ei muutoksia infra-koodiin; tietokantarakenteen oletetaan olevan jo valmiina.

Vastuualue: apps/api

Sallitut polut: apps/api, tests/shopping-lists.test.mjs

Riippuvuudet: Ei riippuvuuksia

Hyväksymiskriteerit:
- API tarjoaa päätepisteet ostoslistojen hakuun (listaus ja yksittäinen lista), luontiin, nimen muokkaukseen ja poistoon.
- API tarjoaa päätepisteet yksittäisen ostoslistan tuotteiden lisäämiseen ja poistamiseen ilman erillistä tallennuskutsua clientilta - muutos tallentuu heti.
- Kaikki ostoslistareitit vaativat voimassa olevan session-evästeen; ilman sitä palautuu 401-virhe samaan tapaan kuin /api/me-reitillä.
- Tallennus käyttää olemassa olevaa DynamoDB-taulua (USERS_TABLE) uusilla avainmalleilla; infra-koodiin ei tehdä muutoksia.
- tests/shopping-lists.test.mjs testaa ostoslistojen CRUD-toiminnot sekä tuotteiden lisäyksen/poiston memoryStore-tallennuksella ja varmistaa kirjautumisvaatimuksen.
- npm run check läpäisee kaikki vaiheet backend-muutosten jälkeen.

## frontend-lists-ui

Lisää frontendiin välilehtinavigointi "Home" ja "Shopping lists" -näkymien välille. "Home"-välilehti on oletuksena aktiivinen kirjautumisen jälkeen. "Shopping lists" -välilehdellä näytetään backendistä haetut olemassa olevat ostoslistat, ja käyttäjä voi luoda uuden listan, avata olemassa olevan muokattavaksi tai poistaa sen. Muokkausnäkymässä listan nimeä voi vaihtaa, tuotteita voi lisätä ja jokaisen tuotteen perässä on "X"-merkki sen poistamiseksi; kaikki muutokset tallentuvat automaattisesti backendin kautta ilman erillistä tallennuspainiketta. Muokkausnäkymästä pääsee palaamaan listojen listausnäkymään.

Vastuualue: apps/web

Sallitut polut: apps/web

Riippuvuudet: backend-lists-api

Hyväksymiskriteerit:
- Sovelluksessa on kaksi välilehteä: "Home" ja "Shopping lists", ja "Home" on aktiivinen heti kirjautumisen jälkeen.
- "Shopping lists" -välilehti hakee ja näyttää backendistä olemassa olevat ostoslistat.
- Käyttäjä voi luoda uuden ostoslistan, avata olemassa olevan muokattavaksi ja poistaa listan.
- Luonti- tai muokkausnäkymässä käyttäjä voi muokata ostoslistan nimeä, ja muutos tallentuu automaattisesti ilman erillistä tallennuspainiketta.
- Jokaisen olemassa olevan tuotteen perässä on "X"-painike, jota klikkaamalla tuote poistuu listalta välittömästi ilman erillistä tallennusta.
- Muokkausnäkymässä on toiminto, jolla käyttäjä palaa ostoslistojen listausnäkymään.
- npm run check läpäisee kaikki vaiheet frontend-muutosten jälkeen.
