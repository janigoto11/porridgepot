# A landing page after user login

Purpose: after login, the user is shown a friendly, initial landing page

## Acceptance criteria

- Instead of the initial "Hello world" - page, we want to show the user
  a "Welcome to the Porridge Pot" message
- We should have header for the app that shows the logged in status
- When you click on the user icon, you can choose to log out (we will add more options later)

## Boundaries

- This should be only a change to the frontend application. Backend or infra changes are not needed.
