# Shopping lists

Purpose: a new tab in the frontend app that gives the user the ability to write and edit shopping lists

## Acceptance criteria

- Add tabs in the frontend - the current one is called "Home", and the new one will be "Shooping lists"
- The "Home" tab will be the active one when the user logs in
- The "Shopping lists" tab shows the existing shopping lists from the database
- User can choose to create a new shopping list, or edit and delete an existing one
- When the user is creating or editing a shopping list, she can also edit its name
- All existing items have an "X" sign at the end so that the user can remove an item from the list
- There is no specific save button for shopping list, the changes are saved automatically
- User has an option to return to the listing of shopping lists

## Boundaries

- This change requires changes in both frontend and backend. The DB setup should be ready.
- No changes to infra code
